# Duotone Filters

Web-based image editor that applies beautiful duotone effects to your photos. Built with Next.js and deployed on Cloudflare Pages.

## Features

- **Drag & Drop Upload** - Simply drag images into the browser or click to select
- **Preset Duotone Filters** - Choose from carefully crafted color combinations
- **Custom Colors** - Create your own duotone effects with custom color pickers
- **Real-time Preview** - See changes instantly as you adjust settings
- **Brightness & Contrast** - Fine-tune your images with additional controls
- **Download Results** - Save your edited images in high quality

## Getting Started

1. **Install dependencies:**

   ```bash
   pnpm install
   ```

2. **Run the development server:**

   ```bash
   pnpm dev
   ```

3. **Open your browser:**
   Visit [http://localhost:3001](http://localhost:3001) to start editing images.

## How to Use

1. Upload an image by dragging it into the drop zone or clicking "Select Image"
2. Choose a duotone filter from the preset options or create a custom one
3. Adjust brightness and contrast to fine-tune your image
4. Click "Save" to download your edited image

## Tech Stack

- **Next.js 15** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Radix UI** - Accessible component primitives
- **Lucide React** - Beautiful icons
- **Cloudflare Pages** - Fast, global deployment

## Deployment

Deploy to Cloudflare Pages:

```bash
pnpm deploy
```
